# 燃費計算アプリ

iPhone向けの燃費・車両記録PWAです。公開URLをSafariで開くだけで利用でき、ホーム画面へ追加すると通常のアプリに近い形で起動できます。

## 公開URL

https://mile-note-fuel.e1x23099.chatgpt.site/

サイトは一般公開されています。URLを友達へ送れば、それぞれのiPhoneで利用できます。

## 主な機能

- トリップメーターの走行距離と給油量から燃費（km/L）を計算
- 37Lの燃料タンク容量に基づく給油量チェック
- 直近の燃費から満タン時の航続距離を推定
- 3か月、6か月、1年、全期間の燃費グラフ
- 月別支出グラフ
- オイル交換などの整備記録
- 故障・修理・カスタム記録
- 車検、保険、税金、洗車などの支出記録
- レシート、整備明細、写真、PDFの添付（1件5MBまで）
- JSON形式のバックアップ書き出し・取り込み
- ホーム画面への追加とオフライン起動

## iPhoneへの追加

1. 公開URLをSafariで開く
2. Safariの共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. ホーム画面の「燃費計算」アイコンから起動する

## データの保存

給油記録、整備記録、支出、添付ファイルは各利用者のiPhone内にあるIndexedDBへ保存されます。サーバーには記録データを送信しません。

- 利用者同士でデータは共有されません
- 同じURLを使っても、それぞれ自分の記録だけが表示されます
- Safari版とホーム画面版は、iOS上で別の保存領域になる場合があります
- Safariの履歴やWebサイトデータを削除すると記録が消える可能性があります
- 端末変更時にデータは自動移行されません

右上のバックアップボタンから定期的にJSONを書き出してください。Safari版からホーム画面版へ移す場合は、Safari版で書き出し、ホーム画面版で「データを取り込む」を選択します。

## アプリの更新

画面や機能を変更して公開版を再デプロイすると、利用者にはService Worker経由で最新版が配信されます。通常はホーム画面へ追加し直す必要はありません。

アイコンやホーム画面上のアプリ名はiOSに保持されるため、それらを変更した場合だけ、バックアップ後にホーム画面から削除して追加し直す必要があります。

## ローカル起動

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

PCでは `http://localhost:4173`、同じネットワーク内のiPhoneでは `http://PCのIPアドレス:4173` を開きます。Service Workerやホーム画面版を正しく検証する場合はHTTPS環境を使用してください。

## 構成

- `index.html`: 画面構造
- `styles.css` / `overrides.css`: レイアウトとiPhone向け調整
- `app.js`: 記録、計算、グラフ、IndexedDB、バックアップ処理
- `manifest.webmanifest`: PWA名とアイコン設定
- `service-worker.js`: オフラインキャッシュと更新管理
- `icons/`: ホイール画像を使用したアプリアイコン
