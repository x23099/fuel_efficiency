# 燃費計算アプリ

iPhoneで使う個人向けの燃費・車両記録PWAです。データと添付ファイルは端末のブラウザ内に保存され、外部サーバーには送信されません。

## 機能

- トリップメーターと給油量から燃費（km/L）を計算
- 37Lの燃料タンク容量に基づく入力チェックと航続距離推定
- 3か月、6か月、1年、全期間の燃費グラフ
- 月別支出グラフ
- 整備、修理、カスタム、車検、保険、税金、洗車の記録
- レシート、整備明細、写真、PDFの添付（1件5MBまで）
- JSONバックアップの書き出し
- ホーム画面への追加とオフライン起動

## 起動

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

同じネットワーク内のiPhoneから `http://PCのIPアドレス:4173` をSafariで開きます。Safariの共有メニューから「ホーム画面に追加」を選ぶと、通常のアプリに近い形で起動できます。

添付ファイルを含むデータはSafariのサイトデータに保存されるため、Safariの履歴・Webサイトデータを削除すると消える場合があります。定期的に右上の書き出しボタンからバックアップしてください。
