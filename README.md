# 燃費計算アプリ

iPhone向けの燃費・車両記録PWAです。公開URLをSafariで開くだけで利用でき、ホーム画面へ追加すると通常のアプリに近い形で起動できます。

## 公開URL

https://mile-note-fuel.e1x23099.chatgpt.site/

サイトは一般公開されています。URLを送れば、それぞれのiPhoneで利用できます。

## ほかの人への共有

1. 変更した機能を配布する場合は、先に公開サイトへ最新版をデプロイする
2. 上記の公開URLをLINEやメールなどで相手に送る
3. 相手のiPhoneでSafariからURLを開き、「共有」→「ホーム画面に追加」を選ぶ
4. ホーム画面のアイコンから起動し、初回だけ自分の車のタンク容量を設定する

「Webアプリとして開く」が表示される場合はオンにして追加してください。Safariの操作手順は[Appleの案内](https://support.apple.com/ja-jp/guide/iphone/iph42ab2f3a7/ios)でも確認できます。

利用者にGitHubアカウントやソースコードのダウンロードは必要ありません。記録と容量はそれぞれの端末に保存され、あなたの記録が相手に共有されることはありません。

## 主な機能

- トリップメーターの走行距離と給油量から燃費（km/L）を計算
- 初回起動時に燃料タンク容量を設定し、端末に保存（概要画面から変更可能）
- 設定した燃料タンク容量に基づく給油量チェック
- 直近の燃費から満タン時の航続距離を推定
- 3か月、6か月、1年、全期間の燃費グラフ
- 月別支出グラフ
- オイル交換などの整備記録
- 故障・修理・カスタム記録
- 車検、保険、税金、洗車などの支出記録
- 給油・車の記録の保存完了ポップアップ（OKで閉じる）、保存中の連打防止、失敗時の入力保持とエラー表示
- レシート、整備明細、写真、PDFの添付（1件5MBまで）
- JSON形式のバックアップ書き出し・取り込み
- ホーム画面への追加

## iPhoneへの追加

1. 公開URLをSafariで開く
2. Safariの共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. ホーム画面の「燃費計算」アイコンから起動する

## データの保存

初回起動時に、お車の燃料タンク容量をL単位で入力してください。保存後は、次回以降の起動時に入力する必要はありません。容量は概要画面の「変更」から修正できます。旧バージョンの記録データが端末に保存されている場合は、従来の37Lを自動で引き継ぎ、設定画面を表示せず、既存の記録も維持します。

設定した容量は給油量の上限と推定航続距離（直近の燃費 × タンク容量）に使用します。燃費（km/L）は従来どおり走行距離 ÷ 実際の給油量で計算します。

タンク容量、給油記録、整備記録、支出、添付ファイルは各利用者のiPhone内にあるIndexedDBへ保存されます。サーバーには記録データを送信しません。

- 利用者同士でデータは共有されません
- 同じURLを使っても、それぞれ自分の記録だけが表示されます
- Safari版とホーム画面版は、iOS上で別の保存領域になる場合があります
- Safariの履歴やWebサイトデータを削除すると記録が消える可能性があります
- 端末変更時にデータは自動移行されません

右上のバックアップボタンから定期的にJSONを書き出してください。Safari版からホーム画面版へ移す場合は、Safari版で書き出し、ホーム画面版で「データを取り込む」を選択します。

バックアップにはタンク容量も含まれ、取り込み時に復元します。容量を含まない旧バージョンのバックアップを取り込む場合は、この端末で設定済みの容量を維持します。Webサイトデータを削除した場合は、初回設定が再び必要です。

## アプリの更新

GitHubリポジトリは https://github.com/x23099/fuel_efficiency です。`main` へのコミット・pushはソースコードの保存です。現在このリポジトリには公開サイトへの自動デプロイ設定を含めていないため、GitHubへの反映と公開サイトの更新は別々に確認してください。

現在の公開先は `.openai/hosting.json` に記録されたSitesプロジェクトです。更新時はこの既存プロジェクトへデプロイし、同じ公開URLを維持します。

画面や機能を変更して公開版を再デプロイすると、次回アクセス時に最新版が配信されます。通常はホーム画面へ追加し直す必要はありません。

iOSと現在のホスティング環境におけるリダイレクト互換性を優先し、Service Workerによるオフライン起動は無効化しています。利用時にはインターネット接続が必要です。

アイコンやホーム画面上のアプリ名はiOSに保持されるため、それらを変更した場合だけ、バックアップ後にホーム画面から削除して追加し直す必要があります。

## ローカル起動

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

PCでは `http://localhost:4173`、同じネットワーク内のiPhoneでは `http://PCのIPアドレス:4173` を開きます。Service Workerやホーム画面版を正しく検証する場合はHTTPS環境を使用してください。

## 構成

- `index.html`: 画面構造
- `styles.css` / `overrides.css`: レイアウトとiPhone向け調整
- `app.js`: 記録、計算、グラフ、IndexedDB、バックアップ処理
- `manifest.webmanifest`: PWA名とアイコン設定
- `service-worker.js`: オフラインキャッシュと更新管理

公開用のファイルは `public/` にも配置しています。画面や処理を変更するときは、ルート直下と `public/` の同名ファイルを同期してください。
